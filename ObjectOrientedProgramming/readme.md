## 💡 Core Concepts Covered

This repository demonstrates the four pillars of OOP and how they apply dynamically in Python:

* **Classes and Objects:** Defining attributes (data) and methods (behavior) using `self` and `__init__`.
* **Encapsulation:** Restricting direct access to data by using private/protected prefixes (`_` and `__`) and getter/setter properties.
* **Inheritance:** Reusing code by deriving new classes from existing ones, utilizing the `super()` function for constructor chaining.
* **Polymorphism:** Implementing method overriding and duck typing where different classes implement the same interface.
